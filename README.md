
# Customer_Shopping_Behavior_Analysis

## 📌 Overview

This project focuses on analyzing customer shopping behavior using Python, MySQL, and Power BI. It follows an end-to-end data analytics workflow, starting with dataset loading and exploration, followed by data cleaning, SQL-based analysis, and interactive dashboard development.

The objective is to demonstrate practical data analytics skills through data processing, querying, visualization, and project documentation.

## 📂 Dataset

The project uses a customer shopping behavior dataset for analysis.

The dataset is used for:

- Exploratory Data Analysis (EDA).
- Data cleaning and preprocessing.
- SQL-based data analysis.
- Power BI dashboard development.

## 🛠️ Tools & Technologies

- **Python:** Dataset loading, Exploratory Data Analysis, data cleaning, and preprocessing.
- **Pandas & NumPy:** Data manipulation and analysis.
- **MySQL:** Data querying and analysis using SQL.
- **Power BI:** Interactive dashboard creation and data visualization.
- **Microsoft Excel:** Supporting data analysis, if required.
- **GitHub:** Project version control and documentation.

## 🔄 Project Workflow

1. **Data Loading:** Importing the dataset into Python.
2. **Exploratory Data Analysis (EDA):** Understanding the dataset and exploring its structure.
3. **Data Cleaning & Preprocessing:** Preparing the data for accurate analysis.
4. **SQL Analysis:** Performing data analysis using MySQL queries.
5. **Dashboard Development:** Building an interactive Power BI dashboard.
6. **Project Documentation:** Creating a project report documenting the analysis workflow.
